# 增强参数与目录说明

> 语言：中文 · [English](../en/parameters-and-layout.md) · [README 中文](../../README.zh-CN.md)

本仓库自洽说明。改数值以各脚本 `__main__` 与 `fgbg_aug.py` 中 dataclass 为准。

**A1～A4 处理细节**（各模式流水线、规格、离线 ×N 槽、在线/离线 A4 差异）：见 [A1-A4增强处理说明.md](A1-A4增强处理说明.md)。

---

## 0. 推荐执行顺序

```text
① extract_pet_by_class.py  → by_class/{image,fg,bg,bbox}/
② split_by_class.py        → splits/{trainval,test}/ + txt（Mac 冒烟 / Linux 全量）
③ dump_aug.py              → AUG_OUT_ROOT/A{1..4}_*/（增强 trainval 全部）
③b split_aug.py            → AUG_SPLIT_ROOT/{A*}/{train,val}/（默认 8:2）
④ compare.py               → A0–A4 + yolo_auto；val+test（评估关增强）
```

| 步 | 脚本 | 角色 |
|:---|:---|:---|
| ① | `extract_pet_by_class.py` | by_class 裁切 + fg/bg |
| ② | `split_by_class.py` / `ensure_split` | 先抽 test；写 txt **并复制** `trainval/`/`test/`；Mac 冒烟 / Linux 全量；列表+目录齐全则复用 |
| ③ | `dump_aug.py` | 增强 **SPLIT_DIR/trainval** 全部 → `AUG_OUT_ROOT` |
| ③b | `split_aug.py` | 划 train/val（`AUG_VAL_RATIO`）；`AUG_VAL_USE_AUG` 控制 val 是否用增强；`INCLUDE_A0` 必含 A0 → `AUG_SPLIT_ROOT` |
| ④ | `compare.py` | 优先 `AUG_SPLIT_ROOT` train/val + `splits/test/image`；齐全则跳过增强 |

## 1. 消融 / 产线模式

| 值 | 训练增强 | 实验角色 |
|:---|:---|:---|
| `none` | 写入未增强 train 图 → `YOLO.train`（YOLO 增强关） | A0 |
| `global` / `fg_only` / `bg_only` / `fgbg` | 写入对应 fgbg 增强图 → `YOLO.train`（YOLO 增强关） | A1–A4 |
| `yolo_auto` | 干净图 → `YOLO.train`（YOLO 增强开） | 产线对照 |

消融与产线都走 Ultralytics classify trainer，**训练日志格式一致**。差异只在「图是否已 fgbg」和「YOLO 自带 aug 开/关」。

**评估（val / test）一律关增强**。选模看 Ultralytics 内部 val；结束后再用干净 loader 重测 `best_val_top1` / `test_top1_at_best_val`。

## 2. 增强规格（`fgbg_aug.py`）

光度类字段为相对幅度：实际因子 `1 + Uniform(-x, x)`，再 `max(0.2, ·)` 钳制。

### 2.1 `FgSpec`（前景，默认弱）

| 参数 | 默认 | 含义 |
|:---|:---|:---|
| `brightness` | `0.08` | 前景亮度抖动幅度 |
| `contrast` | `0.08` | 前景对比度抖动幅度 |
| `rotate_deg` | `90.0` | 刚体旋转半幅（度）；实际角 ∈ `[-rotate_deg, +rotate_deg]` |

前景分支**强制不做 color 抖动**（色相/饱和度），避免拧坏体色斑纹。

### 2.2 `BgSpec`（背景，默认强）

| 参数 | 默认 | 含义 |
|:---|:---|:---|
| `brightness` | `0.28` | 背景区亮度抖动 |
| `contrast` | `0.28` | 背景区对比度抖动 |
| `color` | `0.35` | 背景色彩（饱和度类）抖动 |
| `replace_prob` | `0.55` | 有 `bg_image` 时整幅换成该图（resize）的概率 |
| `noise_sigma` | `10.0` | 背景区高斯噪声 σ（像素值） |
| `blur_prob` | `0.25` | 背景区高斯模糊概率（半径约 1.2） |

未触发 replace 时：挖空前景后约 35% 概率改纯色底，再对背景 mask 做光度/噪声/模糊。

### 2.3 `GlobalSpec`（A1：常规全局增强）

| 参数 | 默认 | 含义 |
|:---|:---|:---|
| `brightness` / `contrast` / `color` | `0.15` / `0.15` / `0.10` | 轻度整图光度 |
| `rotate_deg` | `20.0` | 整图旋转半幅；`expand=True` 防截断 |
| `scale` | `0.10` | 轻度缩放半幅 |
| `shear_deg` | `0.0` | 默认无剪切 |

前景/整图旋转后画布可大于原图，再由 dump/`IMG_SIZE` 统一缩回。

## 3. 脚本入口变量

### 3.1 数据与划分

| 变量 | 脚本 | 含义 |
|:---|:---|:---|
| `DATA_ROOT` / `BY_CLASS_ROOT` | `fgbg_aug` / `train` / `visualize` | 已提取的 `by_class` 根目录 |
| `SPLIT_DIR` | `train.py` / `compare.py` | `trainval.txt` / `test.txt` 所在目录；推荐 `BY_CLASS_ROOT/splits`（`split_by_class.py` 产出），也可用官方 `annotations` |
| `SAMPLE_INDEX` | `fgbg_aug.py` | smoke 取第几张样本 |

### 3.2 训练（`train.py`）

| 变量 | 含义 |
|:---|:---|
| `AUG_MODE` | 见 §1 |
| `WEIGHTS` | 骨干权重：`resnet18` / `yolo11s.pt` / `yolo11l.pt`（检测名会映射为 `*-cls.pt`） |
| `IMG_SIZE` | 输入边长（默认 224） |
| `BATCH` / `EPOCHS` / `LR` / `SEED` | 批大小、轮次、AdamW 学习率、种子 |
| `MAX_CLASSES` | `0`=全部品种；`>0` 只取前 N 类 |
| `MAX_PER_CLASS` | `0`=全量；`>0` 每类最多 N 张 train |
| `NUM_WORKERS` | DataLoader 进程数 |
| `RUN_ROOT` | 输出根（默认本仓库 `runs/`） |

### 3.3 可视化（`visualize.py`）

五列仍为 A0–A4。**仅 A4 `fgbg` 列**走「前景×N 取 1 + 随机复杂背景」（不用同一样本 `bg`）；其余列仍调 `augment()`。

| 变量 | 含义 |
|:---|:---|
| `N_IMAGES` | 拼几行样本 |
| `IMG_SIZE` / `SEED` | 格子边长、种子 |
| `OUT_DIR` | 机制图目录（写出 `pet_aug_grid.png`） |
| `FG_AUG_COUNT` | A4 前景 slot 数（默认 4） |
| `FG_AUG_PICK` | 展示第几个 slot（0-based；选 1 即可） |
| `OTHER_IMAGE_PROB` | A4 背景从其它 `by_class/image` 取模裁切的概率；否则纯色+噪点+条纹 |

说明：当前 **train / compare 的在线 A4** 仍用 `augment(..., mode="fgbg")`；**机制图 / `dump_aug.py` 的 A4** 用 `augment_fgbg_pick`（FG×N + 随机复杂 BG）。

### 3.4 提取（`extract_pet_by_class.py`）— ① by_class 第一步

| 变量 | 含义 |
|:---|:---|
| `PET_ROOT` | 原始 Oxford Pet（`images/` + `annotations/trimaps/`） |
| `OUT_DIR` | 写出 `by_class` 的目标根 |
| `PAD_RATIO` | 身体 bbox 相对扩边 |
| `SKIP_EXISTING` | 四类文件齐全则跳过 |

### 3.5 划分（`split_by_class.py` / `ensure_split`）— ②

一开始就配置三比例；**流程不变**：先抽 test，再在剩余里按 `VAL_RATIO`（相对总量）划 val，其余为 train。  
子集：``MAX_CLASSES`` / ``MAX_PER_CLASS`` 来自 `platform_config`（Mac 冒烟；Linux 全量）。

| 变量 | 含义 |
|:---|:---|
| `TEST_RATIO` | test 占总量比例（默认 `0.1`） |
| `VAL_RATIO` | val 占总量比例；train = 1 − test − val（`0` 则无 val） |
| `SEED` / `SPLIT_SEED` | 划分种子 |
| `MAX_CLASSES` / `MAX_PER_CLASS` | 冒烟截断；`0`=全量 |
| `FORCE` / `FORCE_RESPLIT` | 默认复用完整列表+复制目录；缺任一则重写 |

产出：

- 列表：`train.txt`、`val.txt`、`test.txt`、`trainval.txt`（=train∪val）、`split_summary.json`
- 复制目录（与 by_class 同构）：`trainval/{image,fg,bg,bbox}/<breed>/`、`test/{image,fg,bg,bbox}/<breed>/`

### 3.6 落盘增强（`dump_aug.py`）— ③ 输出增强

接在 ② 之后。源目录固定为 ``SPLIT_DIR/trainval/``（整树增强，**不再**按 train/val 细分）；写出到 ``AUG_OUT_ROOT``（`platform_config`）。

| 变量 | 含义 |
|:---|:---|
| `SPLIT_DIR` / `trainval` | ② 复制出的 trainval by_class 树 |
| `AUG_OUT_ROOT` | 写出根；下含 `A1_global` … `A4_fgbg` |
| `SKIP_EXISTING` | 默认 `True`：已有文件跳过，**不重新增强、不删除** |
| `AUG_COUNT` | A1–A4 每张源图写出槽数（默认 `4`；同倍数公平对比） |
| `OTHER_IMAGE_PROB` | A4 随机背景来自其它图的概率 |
| `IMG_SIZE` | `>0` 统一 resize；`0` 保持裁切尺寸 |
| `INCLUDE_A0` | `True` 时额外写 `A0_none`（同样 ×`AUG_COUNT`） |

目录示例：`AUG_OUT_ROOT/A1_global/<breed>/<stem>__aug01.jpg` … `__aug04.jpg`（A2–A4 同）。

### 3.6b 增强后 train/val（`split_aug.py`）— ③b

接在 ③ 之后。默认 train:val = 8:2；**同一划分套用到所有 A***，保证对比公平。

| 变量（`platform_config`） | 含义 |
|:---|:---|
| `AUG_OUT_ROOT` | ③ 增强产物根 |
| `AUG_SPLIT_ROOT` | 写出根；下含 `A*_*/{train,val}/<breed>/`（含 `A0_none`） |
| `AUG_VAL_RATIO` | val 比例（默认 `0.2` → 8:2） |
| `AUG_VAL_USE_AUG` | `True`（默认）：与现有一致，val 也用 dump/增强图；`False`：先按**原图 stem** 划 val（每 stem 一张原图进 val），剩余 stem 的增强图进 train；此时忽略 `AUG_RANDOM_SPLIT` |
| `INCLUDE_A0` | `True`：必须纳入 `A0_none`；缺失或不完整时从 trainval 补齐 |
| `AUG_COUNT` | 与 dump 同倍数；A0 也写 N 份原图拷贝，保证样本量一致 |
| `AUG_RANDOM_SPLIT` | 仅 `AUG_VAL_USE_AUG=True` 时生效。`False`（默认）：同一源图的全部 `__augNN` 同进 train 或同进 val；`True`：按**文件**全随机划分（各 A* 仍共用同一 `breed/filename` 归属） |

若 `AUG_OUT_ROOT` 尚无 / 不全 `A0_none`，`split_aug` 会从 `SPLIT_DIR/trainval/image` 自动复制原图（resize 与 dump 一致）再划分——**不必重跑 A1–A4**。`INCLUDE_A0=False` 时即使磁盘上有 A0 也不写入 split。

产出另含 `train_stems.txt` / `val_stems.txt`（或随机模式下的 `train_files.txt` / `val_files.txt`）与 `split_summary.json`。

### 3.7 对比训练（`compare.py` / `train.py`）— ④

**优先产线离线数据**（目录齐全则**不再**在线增强 / 重 dump）：

| 用途 | 路径 |
|:---|:---|
| train / val | `AUG_SPLIT_ROOT/<A0_none\|A1_…\|A4_…>/{train,val}/` |
| test | `SPLIT_DIR/test/image/` |

`yolo_auto` 用 `A0_none` 干净 train + YOLO 自带 aug 开；消融臂 YOLO aug 关。  
不齐时回退旧路径（按 `splits/*.txt` 从 `by_class` 物化）。

每组输出 `best_val_top1` 与 `test_top1_at_best_val`（评估关增强）。`MODES` 默认含 A0–A4 与 `yolo_auto`。

| 变量（compare） | 含义 |
|:---|:---|
| `TEST_RATIO` / `VAL_RATIO` / `SPLIT_SEED` | 传给 `ensure_split` |
| `MODES` | 默认 `ALL_MODES` = 五消融 + `yolo_auto` |
| `WEIGHTS` | YOLO 产线必须用 `yolo11*.pt` |
| `EPOCHS` | 上限轮次（Pet 默认 **100**；配合早停） |
| `PATIENCE` | val 连续无提升轮数后早停（默认 **25**；`0`=关） |
| `OPTIMIZER` | 全臂统一，默认 **`AdamW`**（公平对比） |
| `LR` / `LRF` / `COS_LR` / `WEIGHT_DECAY` | → Ultralytics `lr0`/`lrf`/`cos_lr`/`weight_decay` |
| 其余 | `SEEDS` / 冒烟子集等 |

## 4. 目录用途

### 4.1 输入：`by_class/`（通常在外部盘）

示例（统一见 `platform_config.py`，`sys.platform` 分流）：

- Mac：`/Volumes/shunyao-h1/基线数据/Oxford-IIIT Pet/by_class`
- Linux：`/data/samples/base/Oxford-IIIT Pet/by_class`

| 子目录 | 内容 | 用途 |
|:---|:---|:---|
| `image/<breed>/*.jpg` | 身体框裁剪 RGB | `augment` 的 `image`；训练主图 |
| `fg/<breed>/*.png` | RGBA，trimap==1 不透明 | `mask = alpha>0` |
| `bg/<breed>/*.png` | RGBA，trimap==2 不透明 | 可选；demo 可合成背景 RGB |
| `bbox/<breed>/*.jpg` | 原图 + 绿色身体框 | **仅人工检视**；训练/增强不用 |
| `splits/train.txt` | 训练 stem | 可增强 |
| `splits/val.txt` | 验证 stem | **永不增强**；选模 |
| `splits/test.txt` | 测试 stem | **永不增强**；最终对照 |
| `splits/trainval.txt` | train∪val | 兼容旧脚本 |
| `splits/trainval/` | 复制的 train∪val by_class 树 | `{image,fg,bg,bbox}/<breed>/` |
| `splits/test/` | 复制的 test by_class 树 | 同上；不增强 |

### 4.2 输出：本仓库 `runs/`

| 路径 | 用途 |
|:---|:---|
| `runs/compare/<mode>_<tag>_s<seed>/metrics.json` | 含 `best_val_top1`、`test_top1_at_best_val` |
| `runs/compare/compare_summary.json` | 各 mode 的 val/test 均值±标准差 |
| `runs/compare/yolo_auto_*/ultralytics/` | 产线 Ultralytics 训练目录 |

### 4.3 本仓库文件

| 路径 | 用途 |
|:---|:---|
| `fgbg_aug.py` | 核心 `augment()` + by_class 加载（③④ / viz 共用） |
| `extract_pet_by_class.py` | ① 原始 Pet → `by_class` |
| `split_by_class.py` | ② → `splits/{trainval,test}/` + txt（Mac 冒烟 / Linux 全量） |
| `dump_aug.py` | ③ trainval → `AUG_OUT_ROOT` A1–A4（整目录增强） |
| `split_aug.py` | ③b → `AUG_SPLIT_ROOT/{A*}/{train,val}/`（默认 8:2） |
| `compare.py` | ④ 调用 `train_one`，一次跑完 A0–A4（在线增强） |
| `train.py` | 单模式训练（同 ④ 数据路径，在线增强） |
| `visualize.py` | 机制图（可选） |
| `docs/zh/` / `docs/en/` | 本仓库说明文档（含 [A1-A4增强处理说明.md](A1-A4增强处理说明.md)） |
| 外部 `PET_ROOT` | 原始下载；提取脚本读 |

## 5. 改参建议

1. 主链路按 §0：① → ② →（可选 ③）→ ④。
2. 公平消融：只改 `AUG_MODE` / 对比列表，保持三套 Spec 默认。
3. 调强弱：改对应 dataclass；**不要**给前景加 color 或缩放。
4. 机制图：`python visualize.py` → `runs/viz/`。
5. 单模式：`python train.py`。对比表：`python compare.py` → `runs/compare/compare_summary.json`。

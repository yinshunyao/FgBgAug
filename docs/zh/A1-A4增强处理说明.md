# A1～A4 增强处理说明

> 语言：中文 · [English](../en/a1-a4-augmentation.md) · [README 中文](../../README.zh-CN.md)

本文说明 FgBgAug 消融臂 **A1～A4** 各自对图像做了什么、默认参数、离线落盘约定，以及与 A0 / `yolo_auto` 的对照关系。实现以 `fgbg_aug.py`、`dump_aug.py` 为准。

关联总览：[参数与目录说明.md](参数与目录说明.md)

---

## 1. 主张与消融角色

方法不是 MixUp / CutMix 一类「样本混合算子」，而是：**同一张图、前景弱增强 + 背景强增强（双强度）**。推理期模型不变，不增加开销；mask 只在构造训练样本时使用。

| 编号 | 模式名 (`AugMode`) | 离线目录名 | 实验角色 |
|:---|:---|:---|:---|
| A0 | `none` | `A0_none`（可选） | 无 fgbg；仅 resize 等 |
| **A1** | `global` | `A1_global` | **常规全局增强对照**：轻度光度 + 仿射（非有害拧形基线） |
| **A2** | `fg_only` | `A2_fg_only` | 只动前景（弱光度 + 刚体旋转）；背景挖空/不动强增强 |
| **A3** | `bg_only` | `A3_bg_only` | 只动背景（强光度 / 替换 / 噪声模糊）；**前景像素原样贴回** |
| **A4** | `fgbg` | `A4_fgbg` | **主方法**：前景弱 + 背景强（双强度） |
| — | `yolo_auto` | （产线，不经 dump） | 干净图 + Ultralytics 自带 classify 增强 |

期望叙事（机制侧）：

- A1：常规整图增强，旋转 **expand** 后不截断主体。
- A2 / A4：前景弱、无 hue、无缩放；旋转后画布随展开。
- A3：前景几乎不变（像素级贴回）；背景变化大。
- A4 相对 A1：分区双强度；相对 A2/A3：同时利用背景扰动与前景弱几何。

## 2. 输入与 mask

增强入口统一需要：

| 输入 | 来源（`by_class` / `splits/trainval`） | 用途 |
|:---|:---|:---|
| `image` RGB | `image/<breed>/<stem>.jpg` | 主图 |
| FG mask | `fg/<breed>/<stem>.png` 的 **alpha > 0** | 分区 |
| `bg_image`（可选） | `bg/<breed>/<stem>.png` 合成 RGB，或 dump 时另取其它样本图 | A1/A3/A4 背景支路 |

`bbox/` 仅人工检视，**不参与**增强。

光度抖动约定：幅度字段 `x` 表示因子 `1 + Uniform(-x, x)`，再 `max(0.2, ·)` 钳制。

## 3. 默认规格（`FgSpec` / `BgSpec` / `GlobalSpec`）

### 3.1 前景 `FgSpec`（弱）

| 参数 | 默认 | 含义 |
|:---|:---|:---|
| `brightness` | `0.08` | 前景亮度抖动半幅 |
| `contrast` | `0.08` | 前景对比度抖动半幅 |
| `rotate_deg` | `90.0` | 刚体旋转半幅（度），角 ∈ `[-rotate_deg, +rotate_deg]` |

**强制**：前景 **不做 Color（色相/饱和度）抖动**，不做缩放，避免拧坏斑纹/体色。

### 3.2 背景 `BgSpec`（强）

| 参数 | 默认 | 含义 |
|:---|:---|:---|
| `brightness` / `contrast` / `color` | `0.28` / `0.28` / `0.35` | 背景区强光度 |
| `replace_prob` | `0.55` | 有 `bg_image` 时整幅换成该图（resize 对齐）的概率 |
| `noise_sigma` | `10.0` | 背景区高斯噪声 σ |
| `blur_prob` | `0.25` | 背景区高斯模糊概率（半径约 1.2） |

未触发 replace 时：先挖空前景；约 35% 改纯色底；再对背景 mask 做光度 / 噪声 / 模糊。

### 3.3 整图 `GlobalSpec`（A1：常规全局）

| 参数 | 默认 | 含义 |
|:---|:---|:---|
| `brightness` / `contrast` / `color` | `0.15` / `0.15` / `0.10` | 轻度整图光度 |
| `rotate_deg` | `20.0` | 整图旋转半幅；**expand=True** 避免截断 |
| `scale` | `0.10` | 轻度缩放半幅 |
| `shear_deg` | `0.0` | 默认不做剪切（保持「正常」全局增强） |

## 4. 各模式处理流程

实现入口：

- **A1 / A2 / A3**，以及在线 A4：`augment(..., mode=...)`
- **离线 dump / 机制图 A4**：`augment_fgbg_pick(...)`（前景分槽旋转 + 随机复杂背景，不用同一样本 `bg`）

### 4.1 A1 · `global`（常规全局增强）

```text
RGB
  → 仿射：旋转（expand 扩画布）+ 轻度缩放；默认无剪切
  → 整图轻度 Brightness / Contrast / Color
  → 输出（尺寸可能大于原图；dump 再按 IMG_SIZE resize）
```

- **不读 mask 分区**（mask 为空时其它模式会退回原图；global 仍整图处理）。
- 作为「普通全局增强」对照臂，对比分区双强度（A4），而非刻意有害拧形。

**旋转不截断**：前景刚体旋转与 A1 整图旋转均 `expand=True`；A2/A4 会把背景画布中心 pad 到与展开后的前景同尺寸再 blend。

### 4.2 A2 · `fg_only`（仅前景）

```text
RGB + mask
  → canvas = 挖空前景（前景区用背景均值色填充）
  → 前景：弱 Brightness/Contrast（无 Color）
  → 前景：刚体旋转（角 Uniform[-rotate_deg, +rotate_deg]），贴回原画布
  → 输出 = blend(canvas, 旋转后前景, 新 mask)
```

- 背景区**不做** `BgSpec` 强增强（相对 A3/A4 背景更「静」）。
- 用于回答：「只动前景是否足够 / 前景弱增强是否保形」。

### 4.3 A3 · `bg_only`（仅背景）

```text
RGB + mask + 可选 bg_image
  → canvas = _make_background(...)   # replace / 纯色 / 强光度 / 噪声 / 模糊
  → 输出 = blend(canvas, 原始 RGB, 原始 mask)   # 前景像素原样
```

- 前景几何与光度均不变。
- 用于回答：「背景强扰动是否带来增益，而不伤前景外观」。

### 4.4 A4 · `fgbg`（双强度，主方法）

#### （1）在线训练路径：`augment(..., mode="fgbg")`

```text
RGB + mask + 可选 bg_image
  → canvas = _make_background(...)     # 与 A3 相同背景支路
  → 前景：弱光度（无 Color）+ 刚体旋转
  → 输出 = blend(canvas, 旋转前景, 新 mask)
```

#### （2）离线 dump / 机制图路径：`augment_fgbg_pick`

```text
对第 pick 个槽 (0 … N-1)：
  → 前景：weak 光度 + **分槽角度**旋转（prefer 较大 ±角，见 _sample_angle_slot）
  → 背景：make_random_complex_bg
        · 以 other_image_prob（默认 0.65）从其它样本 image 做 wrap-crop
        · 否则：纯色底 + 高对比噪点/色块/弯曲条纹（不用同一样本 bg；密度与对比度偏强）
  → 输出 = blend(复杂背景, 旋转前景, 新 mask)
```

离线 A4 与在线 A4 在「背景如何采样」上有意不同：dump/viz 强调**跨图随机复杂背景**，便于机制图与离线 ImageFolder；在线仍可用同分布 `bg` + `BgSpec`。写论文时建议在协议里写清用的是哪条路径。

## 5. 离线落盘（`dump_aug.py`）

接在 `split_by_class` 之后：

| 项 | 约定 |
|:---|:---|
| 源 | `SPLIT_DIR/trainval/`（整树；**不再**按 train/val 细分） |
| 出 | `AUG_OUT_ROOT`（`platform_config`，默认 `<PET_ROOT>/by_class-aug-A1A4`） |
| 倍数 | **`AUG_COUNT`（默认 4）**：A1～A4 **同一倍数**，保证离线对比公平 |
| 命名 | `<breed>/<stem>__aug01.jpg` … `__augNN.jpg` |
| test | **永不增强** |
| 幂等 | `SKIP_EXISTING=True`：已存在且足够大的文件跳过，不删旧文件 |

目录示例：

```text
AUG_OUT_ROOT/
  A1_global/<breed>/<stem>__aug01.jpg … __aug04.jpg
  A2_fg_only/<breed>/…
  A3_bg_only/<breed>/…
  A4_fgbg/<breed>/…
```

槽位随机性：

- 每张源图、每个 slot：`seed + idx * 10007 + slot * 17`
- A1～A3：每槽独立调用 `augment()`；背景参考图随 `idx + slot * 31` 错开
- A4：每槽 `augment_fgbg_pick(..., pick=slot, n_slots=AUG_COUNT)`

可选 `INCLUDE_A0=True` 时写出 `A0_none`，同样 ×`AUG_COUNT`（内容为原图拷贝）。

## 6. 与训练 / 评估的关系

| 路径 | A1～A4 如何进网络 | 评估 |
|:---|:---|:---|
| 离线 dump 再训 | ImageFolder 读 `AUG_OUT_ROOT/A*_*/` | val/test 用干净划分，关增强 |
| `compare.py` / `train.py` 在线 | 训练时调 `fgbg_aug.augment`（或 A4 在线支路），YOLO 自带 aug **关** | 同上 |
| `yolo_auto` | 干净 train + YOLO 自带 aug **开** | 同上 |

**公平消融**：只换模式（A0～A4），保持三套 Spec 默认与 `AUG_COUNT` 一致；不要只给某一臂加倍数。

---

## 7. 机制检查建议

1. `python visualize.py`：看 1×5，确认旋转后主体完整（无边缘截断）、A3 前景贴回、A4 双强度。
2. 调参：改对应 dataclass；**不要**给前景加 Color 或 scale。
3. 主表消融：Pet/CUB 等协议见论文实验说明；本仓库负责可复现实现与目录。
